# Transferência institucional

Este diretório é o ponto de entrada para a TI assumir o Mangabeira na Escuta. A auditoria foi realizada em 04/09/2026, sem alterar produção, DNS, dados, contas ou credenciais.

## Ordem recomendada

1. Leia o [relatório institucional](RELATORIO_TRANSFERENCIA_INSTITUCIONAL.md).
2. Confira o [conteúdo do repositório](CONTEUDO_REPOSITORIO.md) e o [mapa de dados](MAPA_DADOS.md).
3. Complete o [inventário de credenciais](INVENTARIO_CREDENCIAIS.md) e a [matriz de propriedade](MATRIZ_PROPRIEDADE.md).
4. Siga o [manual de continuidade](MANUAL_CONTINUIDADE.md).
5. Execute a [validação de recebimento](VALIDACAO_RECEBIMENTO_TI.md).
6. Assine o [checklist de entrega](CHECKLIST_ENTREGA_INSTITUCIONAL.md).

## Estado objetivo e bloqueio atual

O frontend, seus assets incorporados, a configuração-base e a documentação estão versionáveis. A transferência ainda é **PARCIAL** porque o código-fonte do Google Apps Script implantado, o schema real da planilha, as configurações do Drive/e-mail e os acessos administrativos externos não puderam ser inspecionados nem exportados do repositório.

Não confunda URL pública de implantação com código-fonte recuperável. A TI deve exportar o projeto Apps Script usando a conta institucional e comparar o contrato descrito nestes documentos antes do aceite.
